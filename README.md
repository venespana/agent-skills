# Agent Skills

[![skills.sh](https://skills.sh/b/venespana/agent-skills)](https://skills.sh/venespana/agent-skills)

Reusable skills for AI agents.

## Installation

```bash
npx skills add venespana/agent-skills
```

## Available Skills

| Skill | What it enforces |
|-------|------------------|
| [depwire](skills/depwire/) | Symbol-level dependency graphs: blast-radius analysis, refactor safety, dead code, security scanning |
| [gdscript-best-practices](skills/gdscript-best-practices/) | Clean code, static typing and architecture rules for Godot 4 scripting |
| [nestjs-best-practices](skills/nestjs-best-practices/) | Layered architecture, DI and validation rules for NestJS |
| [nodejs-best-practices](skills/nodejs-best-practices/) | Clean code, async patterns and SOLID rules for Node.js servers |
| [reactjs-best-practices](skills/reactjs-best-practices/) | Component purity, hooks rules and performance for React apps |
| [validation-flow](skills/validation-flow/) | Risk-tiered validation, tangible evidence packages and delegation doctrine for agentic development |
